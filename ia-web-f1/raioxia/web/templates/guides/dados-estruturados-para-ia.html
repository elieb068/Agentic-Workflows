Uma pessoa lê o seu site e entende que ali tem uma clínica, com endereço e telefone. Um robô precisa adivinhar. Os dados estruturados acabam com a adivinhação: são um bloco de código que diz, de forma organizada, quem é a empresa, onde fica, como falar com ela e o que vende.

O formato: JSON-LD com o vocabulário schema.org

O jeito recomendado é o JSON-LD: um bloco <script type="application/ld+json"> no HTML da página, que o visitante não vê. Os nomes dos campos vêm do schema.org, um vocabulário usado pelo Google, pelo Bing e pelos assistentes de IA. O formato antigo, microdata, também funciona, mas é mais difícil de manter.

Qual tipo usar

  • Organization: para qualquer empresa ou instituição.
  • LocalBusiness ou um tipo mais específico, como Dentist, Restaurant, LegalService ou HairSalon: para quem atende num endereço.
  • OnlineStore: para lojas virtuais.

Tipos como WebSite, WebPage e BreadcrumbList são úteis, mas não dizem quem é a empresa. O Raio-X IA procura um tipo que identifique o negócio.

Exemplo para copiar

Coloque no <head> da página inicial e troque os dados pelos seus:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Dentist",
  "name": "Clínica Sorriso Bom",
  "url": "https://www.sorrisobom.com.br/",
  "logo": "https://www.sorrisobom.com.br/logo.png",
  "telephone": "+55-11-3333-4444",
  "email": "contato@sorrisobom.com.br",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Rua das Flores, 123",
    "addressLocality": "São Paulo",
    "addressRegion": "SP",
    "postalCode": "01234-000",
    "addressCountry": "BR"
  },
  "openingHours": "Mo-Fr 08:00-18:00",
  "sameAs": [
    "https://www.instagram.com/sorrisobom",
    "https://www.linkedin.com/company/sorrisobom"
  ]
}
</script>

O campo sameAs liga o site aos seus perfis oficiais e ajuda a IA a ter certeza de que todos são da mesma empresa.

Onde colocar

  • WordPress: Yoast, Rank Math e outros plugins de SEO geram os dados de Organization ou LocalBusiness a partir das configurações. Preencha nome, logo, endereço e redes sociais.
  • Outras plataformas: procure "código no head", "dados estruturados" ou "schema" nas configurações.
  • Site próprio: peça ao desenvolvedor para gerar o bloco no servidor, para que ele já venha no HTML.

Como validar

  • Validador do schema.org: mostra o que foi encontrado e os erros de formatação.
  • Teste de pesquisa aprimorada do Google: mostra o que o Google aproveita.

Um bloco com um erro de formatação, como uma vírgula sobrando, é descartado inteiro pelos robôs. O Raio-X IA avisa quando encontra um.
