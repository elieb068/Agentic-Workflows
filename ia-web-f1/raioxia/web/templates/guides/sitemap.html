O sitemap é um arquivo com a lista das páginas do seu site, feito para os robôs. Ele não substitui os links entre as páginas, mas ajuda os robôs de busca e de IA a achar tudo o que importa, inclusive páginas novas e páginas que quase não recebem links.

Como ele é

É um arquivo XML, normalmente em seusite.com.br/sitemap.xml:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://www.seusite.com.br/</loc>
    <lastmod>2026-10-01</lastmod>
  </url>
  <url>
    <loc>https://www.seusite.com.br/servicos</loc>
    <lastmod>2026-09-15</lastmod>
  </url>
</urlset>

O <lastmod> é a data da última mudança da página. Os robôs usam essa data para decidir o que visitar de novo, então ela precisa ser verdadeira. Sites grandes dividem a lista em vários arquivos, reunidos num índice (sitemap_index.xml). O formato está em sitemaps.org.

Como criar

  • WordPress: desde a versão 5.5, o WordPress cria o /wp-sitemap.xml sozinho. Plugins como Yoast e Rank Math criam o /sitemap_index.xml.
  • Wix, Shopify, Squarespace: criam o sitemap automaticamente em /sitemap.xml.
  • Site próprio: a maioria dos frameworks tem um gerador. Prefira gerar a cada publicação, para a lista nunca ficar desatualizada.

Declare no robots.txt

Os robôs procuram o sitemap no robots.txt. Acrescente esta linha, com o endereço completo:

Sitemap: https://www.seusite.com.br/sitemap.xml

Ela pode ficar em qualquer lugar do arquivo e vale para todos os robôs. Se o seu sitemap mudou de endereço, atualize a linha: os robôs seguem o endereço declarado, mesmo que ele esteja quebrado.

Envie para o Google e o Bing

No Google Search Console e no Bing Webmaster Tools, há uma área de "Sitemaps" para enviar o endereço. Assim você vê quantas páginas foram encontradas e se houve erros. O Bing também alimenta assistentes de IA, como o Copilot.

Erros comuns

  • O sitemap lista páginas que não existem mais, que redirecionam ou que têm noindex.
  • O robots.txt aponta para um endereço antigo do sitemap.
  • O endereço do sitemap abre uma página do site em vez do XML.
