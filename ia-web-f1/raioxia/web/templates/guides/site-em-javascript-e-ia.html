Muitos sites modernos chegam ao navegador quase vazios: o texto só aparece depois que o JavaScript roda. Para uma pessoa, não faz diferença. Mas a maioria dos robôs de IA não executa JavaScript: eles leem o HTML como ele chega do servidor. Se o texto não está lá, para a IA o seu site é uma página em branco.

Por que isso pesa tanto

O Google executa JavaScript, mas faz isso numa segunda etapa, mais lenta (veja o guia do Google sobre JavaScript). Os robôs das empresas de IA, em geral, ficam só com o HTML. Por isso esse ponto vale 20 de 100 na nota do Raio-X IA, o segundo maior peso, depois do robots.txt.

Como saber se o seu site depende de JavaScript

  1. Abra o site, clique com o botão direito e escolha "Exibir código-fonte da página". Isso mostra o HTML que chega do servidor, o mesmo que a IA lê.
  2. Procure (Ctrl+F) uma frase que aparece na tela, como o título principal ou a descrição de um serviço.
  3. Se a frase não está no código-fonte, e você só encontra algo como <div id="root"></div> ou <div id="app"></div>, o conteúdo depende de JavaScript.

O Raio-X IA faz isso de forma automática: compara as palavras do HTML puro com as que aparecem num navegador de verdade e mostra quanto do texto fica invisível para a IA.

Quem costuma ter esse problema

  • Sites feitos em React, Vue ou Angular "puros" (SPA), sem renderização no servidor.
  • Sites gerados por algumas ferramentas de IA e construtores visuais que entregam um aplicativo JavaScript.
  • Páginas que carregam o texto de uma API depois que abrem, como cardápios, catálogos e listas de imóveis.

WordPress, Wix, Shopify e a maioria das plataformas tradicionais normalmente já entregam o texto pronto no HTML.

Como resolver

  • Renderização no servidor (SSR) ou páginas estáticas (SSG). O servidor monta a página com o texto antes de enviar. Em Next.js, Nuxt, Astro e SvelteKit, isso é o padrão. Em projetos React ou Vue puros, a migração costuma ser o caminho mais sólido.
  • Pré-renderização. Um serviço gera versões em HTML das páginas e as entrega aos robôs. É mais rápido de implantar e não exige reescrever o site.
  • Conteúdo essencial no HTML. No mínimo, coloque no HTML inicial o nome da empresa, o que ela faz, onde atende e como entrar em contato, junto com os dados estruturados.

Depois de corrigir, repita o teste do código-fonte ou faça um novo Raio-X.
